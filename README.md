# GitHub Training Project

## Project Description
This is a simple Flutter mobile application created for Git & GitHub training.

The application contains:
- Home Screen
- AppBar
- Profile Information Cards
- Modern UI Design
- Contact Section

## Technologies Used
- Flutter
- Dart
- Git
- GitHub

## How to Run
```bash
flutter pub get
flutter run
```
